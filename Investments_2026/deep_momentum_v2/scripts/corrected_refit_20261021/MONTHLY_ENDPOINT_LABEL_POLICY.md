# Frozen monthly label decision for the corrected rerun

Decision: keep the current provider-adjusted monthly endpoint objective. This is an explicitly conditional-on-observed-outcomes research baseline, not a certified economic total-return dataset. Action-aware wealth, risk-adjusted labels, stops, trading costs and next-open targets are outside this rerun.

1. Retain every original historical source-ID/signal key. Prediction admission and all feature normalization use only the existing signal-time policy; future endpoint availability or event knowledge must not remove earlier members or predictors.
2. A released return remains `adj_close[exact outcome end] / adj_close[exact prior signal] - 1`, with the unchanged accepted endpoint, request-completeness, observation-cutoff and finite-value checks. No stale close, zero return, payout-as-price, synthetic predecessor bar, extra dividend or second split adjustment is allowed.
3. Unsupported cash/stock/ADS terminal-event months remain unlabelled. Audit the FULL pinned registry (18 current actions plus 11 historical retirements), not only selected RET failures. Where an event retires/converts the predecessor before the month-end mark, a continuing provider alias or suspect post-retirement bar cannot by itself establish the predecessor endpoint. Keep the missing/unverified terminal reason separate from ordinary missing price. Do not interpret all missing ends as terminal events.
4. The previous full-cohort audit found 29 missing-end rows overlapping the 29 registered events; overlap was not proof of economic treatment. Reconcile these exact source/signal rows against the new input version before fitting. If any registry-affected row has become target-available without an independently approved endpoint-continuity decision, stop for an explicit versioned quarantine/rerank impact, rather than silently accept it. Existing dated one-for-one identity handovers retain their explicit reviewed scope; a ticker match or first/last inventory is insufficient.
5. Keep exact descending midpoint ten-class ranking over valid observed outcomes in the unchanged Paper15 prediction cohort. Do not impute missing labels. Retain the original denominator, observed-return and target-availability distinctions, reasons and per-month missingness. Context 80% is not a label coverage threshold.
6. RET retains the same 120 complete calendar months, all ten class cells, equal weight per monthly realized class mean, and causal completed-month cutoff. Restoring a valid source endpoint can rerank other stocks and update payoffs; this is measured and versioned without changing the return objective.
7. Daily execution retains its signed raw-share cash/stock/ADS entitlements, successor marks, retired-order cash slots, unchanged stops and costs. These execution cash flows do not overwrite a predecessor learning price. A close-to-close research label can differ from next-open, stop-managed realized P&L; that is a timing/accounting distinction, not evidence alone of a pipeline defect.

Before the fixed-setting refits, authenticate the installed BK/XOM shadow catalog and independent PASS, reconcile all original keys and the full event registry, apply only separately reviewed field-complete dated RCM/DISCA input changes, and independently check exact non-repaired controls. Rebuild affected targets/ranks/RET and verify their causal windows before any fit. Unknown return/identity and unsupported event evidence remain explicit limitations rather than an indefinite requirement for full historical certification.

Independent verification must check metadata before numerical conversion; exact original membership/request/route masks; disjoint past-feature and forward-outcome data; no protected 2024+ returned values; all changed class-boundary effects; no target-based forecast selection; training-only preprocessing for each annual ten-year window; class-to-probability alignment; frozen hyperparameters/seeds and at most 20 final annual fits with no tuning grid; probability/RET/selection and all daily ledger equations; all old artifacts byte-preserved. A new forecast cohort needs a fresh bounded quote preflight even when the prior selected portfolios had complete paths.

Action-aware monthly wealth returns are a finite separate future accounting experiment. It must cover every full-registry original event episode, whether or not it was traded, with an exact pre-event raw/adjusted basis, dated entitlement, exact successor boundary basis and month-end mark, zero-rate receivable convention and no double-counted source adjustments. Current selected-portfolio evidence does not establish these facts for every historical episode. Such a target version would require all affected monthly reranks/RET recomputation and dependent refits, and cannot be introduced under this frozen endpoint decision.
